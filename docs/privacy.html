AI 提示詞+ 隱私權政策

AI Prompts+ Privacy Policy｜最後更新 / Last updated: 2026-08-10

摘要：提示詞、設定與本機使用次數保存在 Chrome 的本機儲存空間。我們不提供後端、不使用分析或遙測，也不出售資料。只有當你主動選擇「插入提示詞」時，對應內容才會寫入你正在使用的 AI 平台輸入框；擴充功能不會自動送出。

繁體中文

1. 單一用途

AI 提示詞+ 的單一用途是讓使用者在 ChatGPT、Claude、Google Gemini 與 Grok 建立、管理及插入提示詞模板，供使用者檢查後手動送出。

2. 本機處理與儲存的資料

  • 使用者建立的內容：提示詞名稱、分類、提示詞內容、變數名稱與預設值。
  • 設定：介面語言及是否顯示選擇性社群資源提示。
  • 本機功能資料：建立／更新時間、置頂狀態、使用次數與最近使用時間。

上述資料使用 chrome.storage.local 保存在使用者裝置，不會同步到開發者伺服器。匯入與匯出由使用者主動操作，檔案只在使用者選擇的位置與擴充功能內處理。

3. 與 AI 平台的資料傳送

擴充功能在四個支援網站顯示使用者介面。只有使用者明確點擊「插入提示詞」時，選定模板及填入的變數內容才會被寫入該網站的對話輸入框。擴充功能不會自動按下送出鍵；內容是否送出由使用者檢查後自行決定，並受各 AI 平台自身的條款與隱私政策約束。

擴充功能不讀取或上傳既有對話內容、不蒐集附件，也不會把目前頁面網址或提示詞傳給開發者。

4. 權限用途

  • storage：在本機保存提示詞、設定與功能資料。
  • chat.openai.com / chatgpt.com：在 ChatGPT 顯示面板，並依使用者操作插入提示詞。
  • claude.ai：在 Claude 顯示面板，並依使用者操作插入提示詞。
  • gemini.google.com：在 Gemini 顯示面板，並依使用者操作插入提示詞。
  • grok.com：在 Grok 顯示面板，並依使用者操作插入提示詞。

擴充功能不要求 activeTab、瀏覽紀錄、分頁、身分驗證或其他非必要權限，也不執行遠端程式碼。

5. 第三方服務與社群資源

擴充功能沒有分析、遙測、廣告 SDK、後端 API 或資料經紀服務。介面可能顯示由 AI 投資學院+ 提供的選擇性社群資源連結；只有使用者主動點擊才會開啟，並使用 noopener noreferrer、no-referrer，不附帶提示詞或目前對話網址。

6. Limited Use 承諾

本擴充功能對使用者資料的使用遵守 Chrome Web Store User Data Policy（包括 Limited Use 要求）。資料僅用於提供或改善上述單一使用者功能；不出售或移轉給廣告平台、資料經紀商或其他資訊轉售者；不用於個人化廣告、信用評估或貸款；開發者或其他人員不會閱讀使用者的提示詞或對話資料。

7. 使用者控制與安全

  • 可隨時編輯、刪除、匯出或匯入提示詞。
  • 移除擴充功能會依 Chrome 的機制移除其本機資料；建議移除前先匯出需要保留的內容。
  • 資料安全也取決於裝置、Chrome 使用者設定檔及所使用 AI 平台的安全性。

8. 政策更新與聯絡

政策變更時會更新本頁日期；重大變更會透過商店資訊或擴充功能版本說明告知。問題可至 GitHub Issues 聯絡。

English

1. Single purpose

AI Prompts+ lets users create, manage, and insert prompt templates on ChatGPT, Claude, Google Gemini, and Grok for review before manual sending.

2. Data processed and stored locally

Prompt names, categories, content, variable names/defaults, language and promotion preferences, timestamps, pin state, local usage count, and last-used time are stored on the user's device with chrome.storage.local. The developer operates no backend for this data. Import and export happen only when initiated by the user.

3. Data sent to AI platforms

Only when the user selects “Insert Prompt” does the chosen prompt and supplied variable content enter the active AI site's composer. The extension never presses the platform send button automatically; the user reviews and manually sends the content. The platform's own terms and privacy policy apply. The extension does not upload existing conversations or attachments and does not send prompts or the current conversation URL to the developer.

4. Permissions

storage saves local extension data. Host access to chat.openai.com/chatgpt.com, claude.ai, gemini.google.com, and grok.com is used only to display the user-facing prompt interface and perform user-requested insertion. The extension does not request activeTab, history, tabs, identity, or other unnecessary permissions and executes no remote code.

5. Third parties and optional community link

There is no analytics, telemetry, advertising SDK, backend API, or data broker. An optional AI Investment Academy+ resource link opens only after a user click and uses opener/referrer protections; no prompt or conversation URL is attached.

6. Limited Use

Use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the disclosed single purpose; it is not sold or transferred to advertising platforms, data brokers, or information resellers; it is not used for personalized advertising, creditworthiness, or lending; and humans are not allowed to read users' prompts or conversations.

7. User control and contact

Users can edit, delete, import, or export prompts at any time. Before uninstalling, export anything that should be retained. Questions may be submitted through GitHub Issues.
